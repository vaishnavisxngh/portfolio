# ✨ Vaishnavi Singh — Developer Portfolio

Live Website: [https://vaishnavisxngh.vercel.app/](https://vaishnavisxngh.vercel.app/)

GitHub Repository: [https://github.com/vaishnavisxngh/portfolio](https://github.com/vaishnavisxngh/portfolio)

A modern and responsive developer portfolio built with **Next.js**, **TypeScript**, and a clean UI-focused design approach. This portfolio showcases my projects, skills, design philosophy, and development journey as a Computer Science student passionate about frontend engineering, UI/UX, and creative technology.

---

## 🚀 Features

* Responsive modern developer portfolio
* Built using the Next.js App Router architecture
* Smooth animations powered by GSAP
* Interactive 3D elements using Three.js and React Three Fiber
* Fully typed codebase with TypeScript
* Clean and scalable component structure
* Mobile responsive design
* Optimized font loading and performance
* Developer tooling with ESLint + Husky
* Fast deployment workflow using Vercel
* Modern dark-themed UI aesthetic

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/vaishnavisxngh/portfolio.git
```

### 2. Navigate to the Project Directory

```bash
cd portfolio
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open your browser and visit:

```bash
http://localhost:3000
```

---

## 📜 Available Scripts

```bash
npm run dev      # Start development server
npm run build    # Create production build
npm run start    # Run production server
npm run lint     # Run ESLint
```
